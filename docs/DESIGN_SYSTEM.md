# Design System

- 品牌：SideQuest Lab（日常支線任務所）
- 氛圍：Cozy fantasy / 溫暖、耐看、無壓力
- 顏色：`--cream #fbf7ef`、`--ink #243c35`、`--purple #8166a9`、`--mint #b9ded0`、`--peach #f1bc8e`
- 排版：系統字型，最大寬度 1160px，手機 360px 不溢位
- 共用：`site-header`、`nav`、`quest-card`、`btn`、`pill`、`site-footer`
- 互動：按鈕至少 44px 高、清晰 focus ring、文字替代說明、正確空狀態
- 禁止：逐頁創建相互衝突的色票；把外來資料直接寫入 innerHTML；未經授權複製遊戲角色圖
